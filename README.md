# 🌍 Planet-Viruses

**Planet-Viruses** is an interactive educational dashboard that brings together information on well-known viruses and malware around the world, paired with built-in tools designed to help learners understand programming fundamentals, system behavior, and defense concepts.

---

## ⚠️ Disclaimer
This project is intended **strictly for educational and research purposes**. It is designed to promote security awareness, help understand how software and malware operate at a conceptual level, and support learning defense and analysis. The author is not responsible for any misuse or unlawful application of the information or tools provided in this project.

---

## ✨ Features
- **Virus & Malware Encyclopedia:** Structured profiles covering notable malware families, history, propagation methods, and impact.
- **Interactive Dashboard:** Clean, easy-to-navigate interface for browsing entries, categories, and insights.
- **Programming Learning Tools:** Built-in utilities to help understand code logic, core programming concepts, and structured workflows.
- **Safe Learning Approach:** Focused on education and safe exploration without distributing live harmful payloads.
